# Ресурсы Rust и C# в Windows, 17 ноября 2026

Сравнивались установленный C# 1.7.20 из `main` (`14154a29dbab381b6c7dd314e3de9a898615a16e`) и пакет Rust 1.8.10 `1.8.10-20261117-071728-182690d8` из `62895cd97bda5baad13b4b272dcab2a7f9a4b450`. Rust использует программный рендерер Slint. Последующие изменения статуса нехватки места не входят в эти измерения.

## Условия и результаты

Windows, 16 логических процессоров, DPI 144. Активное развёрнутое окно с клиентской областью 2560 × 1494 физических пикселя, карточка Lethal Company, локальная копия с модами, включённые строки песни. Видео, диалоги и помощники закрыты. Проверялись процесс переднего плана, размер окна и отсутствие перекрытия в девяти точках. Окна измерялись последовательно. Перекрытые или изменившие размер интервалы отброшены.

| Метрика | C# 1.7.20 | Rust 1.8.10 |
| --- | ---: | ---: |
| Приватная резидентная память, средние в трёх интервалах | 185,5–213,4 МиБ | 35,1–35,7 МиБ |
| CPU семейства процессов, % общей мощности, взвешенное среднее | 1,04–1,17% | 0,13–0,22% |
| DWM GPU в последнем спокойном сравнении, среднее 55 интервалов | 1,902% | 0,168% |
| DWM GPU в том же сравнении, 95-й процентиль | 1,994% | 0,329% |

Для CPU использованы приращения процессорного времени семейства процессов, разделённые на реальное время и число логических процессоров; сырые счётчики Windows служили сверкой. Память — приватный рабочий набор, а не сумма общей и разделяемой памяти. Три интервала CPU/RAM длились примерно по 24 секунды и включали повтор после сворачивания. У C# игра была установлена, у изолированного Rust — нет: основное действие в карточке различалось.

DWM измерялся отдельно через приращения сырых счётчиков GPU. На каждом интервале выбиралась наиболее загруженная физическая очередь; разные очереди не складывались. Последовательность финальной проверки: Rust 0,190% за 24 интервала, C# 1,902% за 55, Rust 0,168% за 55. Все эти интервалы прошли проверки геометрии, видимости и счётчиков. Между проверками C# был возвращён к исходному размеру и завершён; настройки установленного клиента не менялись.

**DWM относится ко всему рабочему столу.** Эти числа не являются прямым измерением собственного GPU Rust. Для его программного рендерера отдельных строк GPU процесса не было; это считается отсутствием данных, а не нулевой нагрузкой. В более ранних интервалах DWM доходил примерно до 41–51% при тех же приложениях; источник этой изменчивости не доказан. Поэтому итог не переносится на любое оборудование, фоновую нагрузку или видеоплеер. По RAM и CPU преимущество устойчиво в измеренных повторах; результат DWM ограничен указанным спокойным сценарием.

При выключенных строках песни Rust показал 33,6 МиБ приватной резидентной памяти; CPU и DWM были ниже разрешения счётчиков. У C# соответствующего переключателя нет, поэтому это отдельный режим, а не сравнение одинаковой нагрузки.

## Проверка области перерисовки

В отдельной диагностической копии исходников `62895cd` записывались прямоугольники, возвращённые программным рендерером. В пакет для пользователя эта диагностика не включается. Журнал содержал 3 861 диагностическую запись без потерь записей; 1 342 попали в сопоставленный интервал DWM длиной 62,463 секунды.

В этом интервале изменялись только прямоугольники строки песни: 496 × 28 или 496 × 52 пикселя; в 474 кадрах область изменений была пуста. Максимум — 25 792 пикселя, **0,67%** клиентской области. Среднее время CPU-отрисовки по всем 1 342 кадрам — **0,364 мс**, максимум — **1,750 мс**. DWM составил 0,175%.

Это подтверждает частичную перерисовку, но не измеряет время GPU или фактический показ каждого кадра на мониторе. Заданные анимации и их частота не менялись. Проверка не дала основания снижать плавность или добавлять обходные пути в рендерер.

## Границы проверки

Не измерялись одновременно запущенная игра, разные GPU и мониторы, длительное воспроизведение видео, переход между мониторами с разным DPI и точное время каждого кадра непрерывного ресайза.
