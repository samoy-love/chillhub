# Изображения README

`launcher-main.svg` — заглушка на месте главного кадра: список игр, новости,
прогресс загрузки. Настоящий скриншот кладётся сюда под тем же именем (PNG,
1600×900 или больше), а ссылка в обоих README меняется на новое расширение.

Кадры лендинга лежат в `landing/assets/images/` — они обрезаны под его вёрстку
и для README не годятся.
