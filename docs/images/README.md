# Изображения для README

Здесь лежат кадры, которые показываются на главной странице репозитория.
Сейчас это **заглушки** — нейтральные панели без содержимого.

| Файл | Что должно быть на кадре |
|---|---|
| `launcher-main.png` | Главный экран лаунчера: список игр, новости, прогресс загрузки |
| `admin-builds.png` | Админка, раздел сборок: дерево манифеста, версии, активная `latest` |

Заменяются простым копированием поверх, имена менять не нужно — README ссылается
именно на них. Разумный размер — 1600×900 или больше, PNG.

Готовые скриншоты интерфейса есть в `landing/assets/images/`, но они сняты для
лендинга и обрезаны под его вёрстку.
