# Лендинг 2.0: что обязано переехать и что проверено

Опись сделана по разметке и скриптам версии 1.0 (`landing/index.html`,
`landing/scripts/main.js` — 1115 строк) и по публичному API, из которого
страница теперь собирается. Самих файлов 1.0 больше нет: 2.0 переехала
в корень и заняла их место, а прежние лежат в истории git — эта опись
и есть ответ на вопрос «а куда делось вот это».

## Что перенесено по смыслу

| Было в 1.0 | Стало в 2.0 | Почему так |
|---|---|---|
| Волновой фон на канвасе со спиннером-заглушкой | Волновое поле без заглушки | Спиннер ради декоративного фона — не та вещь, ради которой страница ждёт |
| Солнце с вращающимися лучами в заголовке | Убрано | Единственное назначение — привлечь внимание к себе, а не к продукту |
| Наклон карточек под курсором | Убрано | Наведение должно что-то сообщать, а не двигаться |
| Параллакс слоёв | Убрано | Тот же случай |
| Слайдер «было/стало» | Копия лаунчера в браузере | Посетитель не видел старого лаунчера, и сравнивать ему не с чем |
| Игровой автомат с лампочками и звуком | Автомат без лампочек, с отправкой заявки | Аттракцион стал формой: комбинация уходит в те же «Обращения» |
| Шесть карточек с иконками | Нумерованный список шагов | Карточка не умеет показать порядок, а порядок здесь и есть содержание |
| Галочки перед пунктами | Убрано | Стоп-флаг: галочка вместо маркера |
| Лайтбокс для скриншотов | Убрано вместе с галереей | Показывать нечего: живая копия ниже |
| `data-fallback` на картинках | Подмена буквой или скрытие | То же назначение: битая ссылка не оставляет пустой прямоугольник |
| Скелеты картинок | Скелеты картинок и карточек | Разделы приходят из API — форму будущего содержимого надо показать |
| Подпорка для адресной строки iOS Safari | Не нужна | Подпорка держала первый экран ровно в высоту окна; здесь высота набирается содержимым, и схлопывать нечего |
| Звук автомата | Не переносился | В 1.0 он выключен наглухо флагом `DISABLE_REEL_SOUNDS`, то есть на живом сайте его нет |
| Перезагрузка по клику на логотип | Ссылка на себя же | То же действие, и работает средним кликом, и видно, куда ведёт |

## Что появилось

- ~~**Копия главного экрана лаунчера** на данных каталога~~ — убрана с
  сайта позже: раздел «Лаунчер в браузере» пересказывал то, что и так
  видно на снимке первого экрана, а поддерживать вторую копию правил
  клиента приходилось при каждой правке самого клиента.
- **Наполнение из API**: каталог, версии сборок, модпаки, новости, режим
  технических работ, версия лаунчера, значки и обложки игр.
- **Условия использования и политика приватности** — их не было вовсе.
- **Факты об установщике из `/downloads/setup.json`** вместо свёрстанных.
- **Светлая тема**, контраст AA в обеих.

## Что сделано для выкатки

- **Шрифты лежат у себя** (`vendor/fonts/`, 177 КБ на три гарнитуры).
  С чужого домена они не приезжают там, где он недоступен, и заголовки
  съезжают на системную гарнитуру молча — ошибки при этом нет нигде.
- **Превью закрыто от поиска.** Пока настоящая страница живёт в корне,
  две страницы с одним текстом соревновались бы между собой. Строка
  `noindex` снимается тем же коммитом, которым 2.0 переезжает в корень;
  об этом сказано прямо в разметке.
- **Картинка для карточки в мессенджерах открыта обходу.** `robots.txt`
  закрывал `/assets/` целиком вместе с `og:image` — ссылка на сайт
  превращалась в карточку без изображения.
- **Скрытое скрыто.** Собственное правило `display` для элемента сильнее
  встроенного `[hidden]`, и факты об установщике, которых ещё нет,
  показывались подписями без значений: «размер», «собран», «SHA-256» и
  пустота рядом. Правило поставлено общим — по одному такие места
  ловить бесполезно.

## Откуда что берётся

| Элемент | Источник |
|---|---|
| Каталог, модпаки, Steam AppID | `GET /api/games` |
| Значок игры | `iconUrl` → `/manifests/{gameId}/icon.png` |
| Обложка витрины | первый кадр `/content/{gameId}/gallery/gallery.json` |
| Новости и их картинки | `GET /news/index.json`, `coverUrl` |
| Баннер технических работ | `GET /api/maintenance` |
| Версия под кнопкой | `GET /manifests/launcher/latest.json` |
| Размер, дата, SHA-256 | `GET /downloads/setup.json` (пишет релиз) |
| Заявка «какую игру добавить» | `POST /feedback/submit` |

Недоступный источник подставляет снимок настоящего ответа, и страница
говорит об этом один раз, а не под каждым разделом.

## Проверки

`tests/web/static-2.test.js` — 15 проверок статики, которая ломается
молча: шрифты не уходят на чужой домен и все лежат на месте, переменная
гарнитура не возится тремя копиями, превью закрыто от поиска, `og:image`
открыт обходу, у картинок есть размеры и подписи, факты об установщике
спрятаны в разметке, а не свёрстаны.

`tests/web/landing2-dom.test.js` — 21 проверка страницы целиком в jsdom:
настоящий `index.html`, все скрипты в том же порядке, сеть подменена и
записана. Проверяется наполнение из каталога, поведение без сервера,
факты об установщике, копия лаунчера, отправка заявки и мелочи, которые
ломают страницу молча, — год в подвале, `alt` у картинок, скрытые от
озвучки барабаны.

## Что осталось на релиз

`/downloads/setup.json` рядом с установщиком:

```json
{ "size": 123731968, "builtAt": "2026-09-04T03:12:00Z", "sha256": "…" }
```

Без него размер, дата и хеш не показываются вовсе — вместе с абзацем про
сверку контрольной суммы. Свёрстанными их держать нельзя: числа
устаревают на следующей сборке, а свёрстанный хеш — это опубликованная
рядом с кнопкой скачивания ложь.
