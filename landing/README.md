# ChillHub Landing

Статический сайт-лендинг лаунчера с параллаксом, анимациями и фоном «лавовая лампа».

## Структура
- `landing/index.html` — разметка
- `landing/styles.css` — стили и оформление
- `landing/scripts/main.js` — анимации и интерактив
- `landing/assets/` — иконки и изображения (плейсхолдеры)

## Локальный предпросмотр
Открой `landing/index.html` в браузере. Для корректной работы некоторых фич лучше использовать простой http-сервер (например, `npx serve` или расширение Live Server).

## Настройка
- Замените изображения в `assets/images/` на реальные скриншоты.
- Ссылку кнопки «Скачать для Windows» укажите на твой установщик NSIS.
- Раздел «Игры и моды» расширяется новыми карточками.
