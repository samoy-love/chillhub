# Chill Hub Landing

Статический сайт-лендинг лаунчера с параллаксом, анимациями и фоном
«лавовая лампа». Раздаётся nginx с корня `launcher.samoy.love`.

## Структура

- `index.html` — разметка
- `styles.css` — стили и оформление
- `scripts/main.js` — анимации и интерактив
- `assets/icons/` — логотип
- `assets/images/` — скриншоты лаунчера и админки, обложки игр

## Локальный предпросмотр

Для вёрстки достаточно открыть `index.html` в браузере, но часть возможностей
требует http-сервера (`npx serve` или расширение Live Server): из `file://`
не работают относительные пути и часть анимаций.

Кнопка «Скачать для Windows» ведёт на `/downloads/ChillHub-Setup.exe` — этот
путь отдаёт nginx с сервера, локально он не откроется.

## Что менять

Карточки в разделе «Игры и моды» добавляются в `index.html` вместе с обложкой
в `assets/images/`.

Пережать картинки (в том числе в WebP) — `scripts/compress-images.ps1` из
корня репозитория.

Изображения здесь сняты под вёрстку лендинга и обрезаны под неё. У README
репозитория свои кадры — в `docs/img/`, требования к ним описаны там же.
