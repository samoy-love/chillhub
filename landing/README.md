# Chill Hub Landing

Статический сайт лаунчера. Раздаётся nginx с корня `launcher.samoy.love`.
Сборщика нет: браузер получает ровно те файлы, что лежат здесь.

## Структура

- `index.html` — главная, `privacy.html` и `terms.html` — правовые страницы
- `styles.css` — оформление всего сайта, `emu.css` — только эмулятор
- `app.js` — поведение страницы, `api.js` — обращения к публичному API
- `emu-core.js` — что эмулятор считает, `emu.js` — как показывает
- `vendor/` — шрифты своей копией: сторонний CDN знал бы каждого читателя
- `assets/icons/` — логотип, `assets/images/` — снимки и обложки игр

## Локальный предпросмотр

Для вёрстки достаточно открыть `index.html` в браузере, но часть возможностей
требует http-сервера (`npx serve` или расширение Live Server): из `file://`
не работают относительные пути и часть анимаций.

Кнопка «Скачать для Windows» ведёт на `/downloads/ChillHub-Setup.exe` — этот
путь отдаёт nginx с сервера, локально он не откроется. Витрина игр приходит
из публичного API; без него страница показывает встроенный пример, а не
пустоту.

## Что менять

Карточки в разделе «Игры и моды» приходят из реестра игр — правятся они в
админке, а не здесь. Встроенный пример на случай недоступного API лежит в
`api.js`.

Пережать картинки (в том числе в WebP) — `scripts/compress-images.ps1` из
корня репозитория.

Изображения здесь сняты под вёрстку сайта и обрезаны под неё. У README
репозитория свои кадры — в `docs/img/`, требования к ним описаны там же.
