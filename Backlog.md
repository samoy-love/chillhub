# Backlog (Launcher + Servers)

## Обратная связь (Feedback)

- **Кнопка в лаунчере**
  - Расположение: под основной кнопкой `ActionBtn`.
  - Визуал: полупрозрачная, еле заметная, с цветной обводкой; «прикольная» надпись (варианты):
    - «Поделиться идеей ✨»
    - «Сообщить о проблеме 🛠️»
    - «Написать нам 💬»
  - Клик -> модальное окно с полями:
    - Имя (опционально)
    - Контакт (Telegram @username / e‑mail / иной)
    - Комментарий (редактор с базовым форматированием: жирный/курсив/список/ссылка)
    - Тип обращения (список: Баг / Идея / Вопрос)
    - Чекбокс «Приложить логи/системную инфу» (по согласию, с подсказкой что именно прикладываем)
  - Поведение отправки:
    - Отправка в API; при оффлайне – поставка в локальную очередь, фоновые ретраи.
    - Видимый статус: «Отправлено» / «В ожидании отправки» / «Ошибка, повторить?»

- **Раздел в админке: Inbox обращений**
  - Представление: таблица/список карточек с полями: время, тип, имя, контакт, превью комментария, флаг «важное», статус.
  - Действия:
    - Очистить список целиком (с подтверждением).
    - Удалить конкретное обращение.
    - Отметить «важное» (галочка). Отложенные/важные фильтруются по отдельной галочке/фильтру.
    - Просмотр карточки: по нажатию открывается «читатель» с полным текстом. Внутри:
      - Горячая клавиша «Delete» (или Del): удалить и автоматически перейти к следующему в текущей выборке/фильтре.
      - После удаления запись исчезает и из списка на странице (live‑обновление через websocket или опрос).
  - Фильтры/поиск: по типу, по «важному», по тексту/контакту, по дате.
  - Статусы: Новый / Прочитан / Удалён.
  - Аудит: логировать кто удалил/пометил «важным». 
  - Минимальные критерии готовности (DoD):
    - Создание, чтение, удаление, установка/снятие «важное» работают; UI обновляется без перезагрузки.
    - Горячая клавиша для удаления и перехода к следующему работает и в полноэкранном просмотре.

## Режим технических работ

- Флаг с сервера включает режим: блокирует установку/обновление/запуск (или только часть, по параметрам сервера).
- Пользователь видит баннер с причиной и ETA завершения.
- После окончания — автоматическое возвращение к нормальному режиму без перезапуска клиента.

Критерии: режим включается/выключается по API, баннер отображается, кнопки корректно блокируются, логика автосброса работает.

## Метрики и алерты (минимальные требования)

- **Лаунчер (клиент)**
  - DAU/MAU; число запусков клиента.
  - Установки/обновления игр (шт/день, байты скачивания, средняя скорость, ошибки/откаты).
  - Время установки/обновления; процент успешных операций.
  - Ошибки (коды + контекст), падения; версия клиента.

- **API/Сервер**
  - HTTP RPS, p50/p95/p99 latency по endpoint’ам.
  - 4xx/5xx в разрезе endpoint/версии.
  - Health/ready флаги, пулы соединений к БД, ошибки БД.

- **Nginx/прокси**
  - RPS, 4xx/5xx, upstream latency, size ответов, кеш‑хиты (если есть), сертификаты (срок жизни).

- **Статика/скачивание**
  - Отдача файлов: bytes served, скорость, ошибки/обрывы.
  - Топ загружаемых ресурсов; хэши манифестов (верификация).

- **Деплой**
  - Успех/неуспех шагов, длительность, версия релиза/коммита.
  - Проверки после деплоя (smoke‑tests: HTTP 200/401/302 по ключевым точкам, доступность манифестов, хэши файлов).

- **Инфраструктура** (минимально)
  - CPU/RAM/Disk/FDs по сервисам; аптайм; рестарты unit’ов.

- **Алерты в Telegram** (простые пороги)
  - API: p95 > 800ms 3мин; 5xx > 1% 3мин; Health=DOWN немедленно.
  - Nginx: 502/504 > 1% 3мин; сертификат < 14 дней — предупреждение.
  - Деплой: шаг упал; смоки не прошли.
  - Клиент: скачивания «ошибка» > N за 10мин.
  - Формат: «[sev][компонент] событие, метрика=X (порог=Y), ссылка на дашборд/логи». 

Примеры стеков: Prometheus/OpenTelemetry + Grafana; алерты → Telegram‑бот (webhook).

## Уведомления (Push/Toasts/Баннеры)

- **Новая версия лаунчера**
  - Тост: «Доступна новая версия лаунчера vX.Y. Обновить сейчас?» [Обновить] [Позже]
  - Баннер: «Мы улучшили стабильность и скорость. Обновитесь до vX.Y.» [Смотреть изменения] [Обновить]

- **Технические работы**
  - Баннер (жёлтый): «Идут техработы до HH:MM. Установка/обновление временно недоступны.» [Подробнее]
  - Тост перед началом: «Через 5 минут начнутся техработы.» [Ок]

- **Критический фикс**
  - Баннер (красный): «Критическое обновление безопасности. Рекомендуем обновиться сейчас.» [Обновить]
  - Тост: «Вышел критический фикс. Обновиться?» [Обновить] [Позже]

- **Новая сборка/контент**
  - Тост: «Новая сборка для <Игра>. Смотреть изменения?» [Открыть] [Скрыть]

Поведение:
- Тосты автоисчезающие (6–8с), с возможностью закрепить.
- Баннеры — до взаимодействия/снятия условия (например, режим техработ).
- Все кликабельные действия трекаются в метриках.
