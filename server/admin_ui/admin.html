Тест параметров загрузки (подбор размера чанка и параллельности)
Загружает пробный кусок выбранного файла с каждой комбинацией «размер чанка × параллельность» на сервер и сразу отбрасывает загруженное (/admin/api/upload/abort), не создавая версию и не трогая манифесты. Значения по умолчанию рассчитаны на архивы порядка 10–15 ГБ — для более мелких сборок пробу и чанки стоит уменьшить, иначе сама проба займёт заметную долю времени полной заливки.
